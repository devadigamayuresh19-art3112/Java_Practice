# 🚀 Java Practice Repository

Welcome to my **Java Practice Repository**! This repository is a organized collection of Java programs, algorithm implementations, and data structure solutions created as part of my continuous learning journey in core Java programming.

---

## 🛠️ Topics Covered

- **Basics & Control Flow:** Input/Output handling, conditional statements, loops (`for`, `while`, `do-while`).
- **Functions & Methods:** Modular programming, pass-by-value, recursive functions.
- **Arrays & Strings:** 1D & 2D array manipulation, string operations, dynamic arrays.
- **Sorting & Searching Algorithms:** 
  - Bubble Sort
  - Selection Sort / Insertion Sort
  - Binary Search / Linear Search
- **Number Theory & Math Problems:**
  - Prime Number checking
  - Factorials (Iterative & Recursive)
  - Fibonacci Series, Armstrong Numbers, etc.
- **Object-Oriented Programming (OOP):** Classes, Objects, Inheritance, Polymorphism, Encapsulation, Abstraction.
